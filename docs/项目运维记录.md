自动部署（GitHub webhook，commit `4ba01f3` 起已加固）：
- 仅文档/说明类改动（docs/、*.md、.gitignore 等）→ 只 `git pull`，**不构建**
- 代码改动 → `git pull` + 清空 `.next` 干净构建 + 校验 BUILD_ID + `pm2 restart`；构建日志落盘 `/tmp/zbjh-deploy.log`，失败记录见 Supabase `transactions` 表（type=deploy_ping）
- 锁文件 `/tmp/zbjh-deploy.lock` 成功/失败均自动清理；若残留且无构建进程，新推送自动放行（commit `f724adc`）
- 若自动构建失败，`.next` 可能不完整，需手动：`pm2 stop ai-writer && rm -rf .next && npm run build && pm2 restart ai-writer`
- 若自动构建正在进行，手动构建会报 "Another next build process is already running"，应等待或先停掉再构建
